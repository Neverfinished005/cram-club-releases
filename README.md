# Lockrew (formerly Cram Club) — Android test builds

Study with friends on one shared timer. Everyone sees who leaves early.

## Install

1. Open the [latest release](https://github.com/Neverfinished005/cram-club-releases/releases/latest) and download **CramClub.apk**.
2. Tap the downloaded file. If Android asks, allow installing apps from this source.
3. If Google Play Protect says the app isn't recognised, tap **More details → Install anyway** (it isn't on the Play Store yet).
4. Open Lockrew and tap **Continue with Google**. If you see "Google hasn't verified this app", tap **Advanced → Go to** the app.

Android only for now. Installing a newer version over the old one keeps your data, and from 1.4.1 on, updates arrive inside the app.
